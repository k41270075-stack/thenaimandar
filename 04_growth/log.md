# Журнал привлечения: кого позвали и что получилось

Заполняем **каждый день**, иначе к 14 октября нечего будет показать на слайде
«Результат» (35 баллов из 100).

Что важно помнить при заполнении:

- Ventorme считает регистрации сам, **мы их не видим**. Поэтому наша колонка —
  это не регистрации, а то, что мы можем измерить: сколько позвали и сколько
  нажали на кнопку (видно в Яндекс Метрике, если она подключена в
  `03_landing/site/config.js`).
- Засчитывается только человек, который **зарегистрировался по нашей ссылке и
  прошёл онбординг**. Поэтому «позвали 50 человек» — не достижение.
  Достижение — «были рядом и помогли дойти до конца».
- Для сравнения: на главной Ventorme до страницы регистрации доходят 25,2%
  посетителей (Т1). Это цифра, с которой мы сравниваем свою.

## По каналам

Одна строка — одно обращение к группе людей. Канал пишем так, чтобы потом
было понятно, что именно сработало.

| Дата | Канал (конкретно) | Кто звал | Сколько человек увидели | Нажали кнопку | Комментарий |
|---|---|---|---|---|---|
| | напр. «11Б класс, WhatsApp» | | | | |
| | напр. «чат подготовки к ЕНТ, Telegram» | | | | |
| | напр. «сторис в Instagram» | | | | |
| | напр. «казахский класс 10А, лично» | | | | |

**Колонка «Сколько человек увидели»** — это не размер чата, а честная оценка:
сколько людей реально прочитали сообщение. Если не знаем, пишем «?» и не
придумываем.

## Школьные встречи (самый сильный канал)

Один классный час с 25 людьми, которым мы помогаем дойти до конца онбординга,
обычно даёт больше, чем все чаты вместе: там человек проходит регистрацию
при нас, а не «потом как-нибудь».

| Дата | Школа и класс | С кем договорились | Сколько было | Сколько прошли до конца | Фото / письмо учителя |
|---|---|---|---|---|---|
| | | классный руководитель / психолог / завуч | | | есть / нет |

После каждой встречи сразу:

- [ ] фото зала (с разрешения, без лиц крупным планом);
- [ ] короткое сообщение или письмо от учителя, что встреча была полезна;
- [ ] записать, сколько человек застряли и на каком шаге — это наблюдение для
      презентации, не хуже кастдева.

Зачем фото и письмо: если организаторы спросят, откуда всплеск регистраций,
у нас есть доказательство честного источника. И это сильный слайд для финала.

## Красные линии (нарушение = дисквалификация)

Перед каждой новой волной приглашений перечитать:

- ❌ Платная реклама, включая платные посты в пабликах.
- ❌ Боты, накрутка визитов, фейковые аккаунты.
- ❌ Один человек регистрируется дважды (с двух почт, через Google и почту).
- ❌ Регистрировать кого-то «за него» со своего телефона.
- ❌ Платить или дарить что-то за регистрацию.
- ✅ Можно: звать лично, в школьных чатах, в своих соцсетях, через школу.

Тексты сообщений на русском и казахском — в
[distribution.md](distribution.md), раздел «Тексты сообщений».
