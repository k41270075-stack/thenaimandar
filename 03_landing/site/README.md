# Код лендинга

Чистый HTML, CSS и JavaScript, без сборки и без зависимостей. Любой файл
можно открыть двойным щелчком и смотреть результат сразу.

| Файл | Что это |
|---|---|
| `config.js` | **Единственное место, которое надо заполнить руками.** Номер команды, Метрика, свой лог |
| `index.html` | Русская версия лендинга |
| `kz/index.html` | Казахская версия |
| `test.html` | Техническая страница: проверка, ломается ли вход через Google во встроенном браузере |
| `styles.css` | Вся вёрстка, mobile-first |
| `app.js` | Логика: ссылка команды, определение встроенного браузера, мини-вопрос, события |

## 1. Заполнить перед публикацией (обязательно)

1. **Номер команды** в `config.js`, поле `TEAM`, формат `"team-17"`.
   Пока он не заполнен, на странице видно красное предупреждение, а в
   консоли — ошибка. Это сделано специально: ошибка в номере = регистрации
   уйдут другой команде.
2. **Тексты про продукт можно публиковать сразу**: в них написано только то,
   что подтверждается сайтом или материалами кейса.
   - ✅ список возможностей и ответ «Это бесплатно?» сверены с ventorme.ai
     12.10 (Free: мини-тест, уровень IELTS/SAT, портфолио; остальное в Plus).
     Калькулятор гранта по ЕНТ на сайте не найден, поэтому убран. «Карта не
     нужна» убрано: это нигде не подтверждено.
   - Блок «Как это работает», шаг 2 пока написан общими словами («короткий
     онбординг, несколько шагов»): в кейсе сказано только, что онбординг есть.
     После того как кто-то из команды пройдёт регистрацию сам (PLAN.md,
     день 0), замените его на конкретику: сколько шагов, что именно
     спрашивают, сколько минут занимает. Конкретика конвертирует лучше.

3. **Казахскую версию вычитывает носитель языка** в команде. Текст написан
   как черновик, до вычитки `kz/` не публикуем.

## 2. Как выложить

Самый быстрый способ — **Netlify Drop**: открыть <https://app.netlify.com/drop>
и перетащить туда папку `site`. Ссылка появляется сразу, аккаунт можно
создать потом (иначе ссылка живёт недолго — аккаунт нужен обязательно,
лендинг должен работать до конца хакатона).

Альтернативы: Vercel, GitHub Pages из **отдельного публичного** репозитория
только с кодом лендинга (данные кейса публиковать нельзя, п. 13.5 Положения).

## 3. Что проверить после публикации

- [ ] Открывается в режиме инкогнито по публичной ссылке.
- [ ] Нажать кнопку → в адресной строке есть `team-` и **наш** номер.
- [ ] Открыть с телефона: кнопка видна без прокрутки, текст читается без увеличения.
- [ ] Закреплённая кнопка внизу не закрывает текст и не исчезает.
- [ ] Отправить ссылку себе в Instagram, открыть оттуда: появилась ли жёлтая
      подсказка про встроенный браузер.
- [ ] На Android из Instagram нажать «Открыть в Chrome» — открылся ли Chrome.
- [ ] На iPhone из Instagram нажать «Скопировать ссылку» — скопировалась ли.
- [ ] Повторить из Telegram и WhatsApp.
- [ ] Переключатель RU/ҚАЗ работает в обе стороны.
- [ ] `?debug=1` в конце ссылки показывает платформу, встроенный браузер и
      номер команды — удобно во время тестов на чужих телефонах.

## 4. Как тестировать гипотезу И

Страница `test.html` для этого и сделана: открываешь её из Instagram,
она показывает, что видит про браузер, ведёт на настоящую регистрацию и
записывает результат. Строку с результатом она копирует в буфер — её надо
вставить в `01_analysis/causes.md`, раздел «Гипотеза И».

Ссылку на `test.html` можно давать и жюри: проверка воспроизводится на любом
телефоне за 10 секунд. Это сильнее, чем слайд со скриншотом.

## 5. Своя статистика (необязательно, но полезно)

- `METRIKA_ID` + `METRIKA_ENABLED: true` включают Яндекс Метрику и маленькую
  полоску про cookie снизу. Пока выключено — полоски нет вообще.
- `LOG_URL` — свой приёмник событий. Метрика во встроенных браузерах часто не
  прогружается, то есть именно по самому важному сегменту цифр не будет.
  Свой лог это закрывает. Подойдёт Google Apps Script, который пишет в
  Google Таблицу.

События, которые отправляются: `page_view`, `inapp_view`, `quiz_answer`,
`cta_click` (с указанием кнопки), `escape_chrome`, `copy_link`, `share_click`,
`scroll_50`, `inapp_test`.

## 6. Чего в коде сознательно нет

- Своей формы регистрации: кнопка ведёт только на ссылку команды.
- Лишних параметров в ссылке регистрации: организаторы считают регистрации по
  ней, ломать её ради своей аналитики нельзя. Какую кнопку нажали — пишется в
  свой лог, а не в ссылку.
- Больших баннеров поверх первого экрана, анимаций, внешних шрифтов и
  библиотек: страница должна открываться за 2–3 секунды внутри Instagram.
- Картинок, которые выглядят нажимаемыми: на главной Ventorme на такие
  элементы нажали 20,5% посетителей с телефона (Т9).
