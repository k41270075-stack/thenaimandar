# Прототип «Первые 5 минут»: работа на 2 разработчиков

Прототип показывает, что видит ученик после анкеты Ventorme, а Telegram-бот **Ventorme AI** возвращает его на следующий день. Сценарий и эффекты описаны в [../06_final/final_plan.md](../06_final/final_plan.md), разделы 3–5.

Каркас уже работает: откройте `index.html`, и путь S0 → S7 проходится по заглушкам. Каждый участник заменяет заглушки **только своих экранов** и правит **только свои файлы**, поэтому при слиянии конфликтов нет.

> **Порядок работы, время и критерии готовности: [DEV_PLAN.md](DEV_PLAN.md).**
> **Обязательно: все анимации делаются через скилл моушн-дизайна (motion design skill).**
> **Стиль один с лендингом** `03_landing/site`: токены, кнопки, панели и чипы уже лежат в `css/base.css`, свои цвета и шрифты не заводим.

## Кто что делает

| Участник | Что делает | Свои файлы (правит только он) |
|---|---|---|
| **1. Экраны** | S0 последний вопрос анкеты, S1 сканер Venti, S2 сундук с результатом, фон `#bg`, S3 одна кнопка, S4 мини-вызов 60 с, S5 level up и замок | `js/part1.js`, `css/part1.css`, `data/profiles.js`, `js/part2.js`, `css/part2.css`, `data/questions.js` |
| **2. Бот и возврат** | Telegram-бот Ventorme AI (ИИ-помощник и напоминания), S6 «Подключи Venti», S7 «Завтра», демо-меню, деплой на Vercel | `js/part3.js`, `css/part3.css`, `api/*`, `bot/*`, `package.json`, `vercel.json`, `DEPLOY.md` |
| **Капитан** | Презентация, спич, сбор данных (опрос, кастдевы, полевой тест) | `06_final/*`, слайды |

Участник 1 может вести два Claude одновременно: один на S0–S2 (`part1`), второй на S3–S5 (`part2`). Файлы у них не пересекаются.

**Общие файлы, никто не меняет:** `index.html`, `css/base.css`, `js/state.js`, `js/router.js`, `js/fx-core.js`, `js/hud.js`, `js/main.js`, `img/*`. Если без правки общего файла никак, напишите об этом в итоге работы, а не правьте сами.

## Договорённости (API каркаса)

```js
// Экран
Screens.register('s3', {
  enter: function (el, state) { el.innerHTML = '...'; },  // вызывается при каждом входе
  leave: function (el) {}                                 // по желанию: остановить таймеры
});
go('s4');                       // перейти; или кнопка <button data-go="s4">

// Состояние (localStorage, ключ vt5min-v1)
State.get();                    // { screen, answers:{grade,goal,field}, profileId, xp, level, streak,
                                //   lastActive, plan, challenge:{correct,total,done}, lockedUni,
                                //   badge5min, notify:{tg,wa,email,contact,time}, tomorrow }
State.set({ plan: 25 });        // частичное обновление, шапка обновится сама
State.addXP(30);                // → { levelUp, level }; 100 XP = уровень
State.reset();                  // сброс демо, возврат на S0
document.addEventListener('state', e => e.detail.prev / e.detail.next);

// Эффекты
FX.countUp(el, 34, { ms: 1200, suffix: '%' });
FX.confetti(); FX.flash(); FX.shake(el); FX.vibrate([30, 50, 80]);
FX.sound('ding' | 'pop' | 'error' | 'levelup');   // без файлов, после первого тапа
FX.wait(500); FX.reduced;       // reduced = пользователь просил меньше движения

// Шапка
HUD.flyXP(buttonEl, 30);        // «+30 XP» летит в шапку и начисляет XP → Promise<{levelUp}>
HUD.bump('streak' | 'level' | 'xp');
document.addEventListener('demo:menu', ...);  // тройной тап по логотипу (ловит участник 2)
```

**Готовые элементы стиля из `css/base.css`** (берите их, а не рисуйте свои):
`.btn` (пилюля, синий) + `<span class="btn-arrow"></span>`, `.btn-lime`, `.btn-ghost`, `.btn-glow` (дышит свечением), `.panel` > `.panel-core` (вложенный корпус), `.card`, `.chips` > `.chip[aria-pressed]`, `.h1` с `<em>` (переливающийся градиент), `.h2`, `.lead`, `.tag-example`.
Токены: `--accent`, `--lime`, `--violet`, `--good`, `--bad`, `--fire`, `--surface-1/2`, `--hairline`, `--ink`, `--ink-muted`, радиусы `--r-pill/panel/card/chip`, кривая `--ease`, пружина `--ease-spring`. Светлая и тёмная тема работают сами.

**Что передаётся между участниками через `State`:**
- Участник 1 в S0 записывает `answers.grade`, `answers.goal` (`ent`, `sat`, `ielts`, `unknown`), `answers.field` (`it`, `med`, `biz`) и `profileId`. В S5 ставит `streak: 1`, `lastActive`, `plan: 25`, `badge5min: true`, `challenge`. Из S5 ведёт на `s6`.
- Участник 2 в S6 строит ссылку на бота из `answers` и `profileId`, в S7 ставит `streak: 2`, `lockedUni: false`, `tomorrow: true`.

**Правила для всех:**
- Мобильный экран до 430px, касаемые элементы от 48px, шрифт от 15px.
- Анимировать только `transform` и `opacity`. Каждый эффект не дольше 1,5 с и пропускается тапом.
- Учитывать `FX.reduced`: без движения, только появление.
- Все цифры подписаны «пример» (класс `.tag-example`).
- Классы CSS только с префиксом своих экранов (`.s2-chest`, `.s4-timer`, `.s6-bot`), чтобы стили не пересекались.
- Внешние библиотеки только через CDN с точной версией (на странице) или через `package.json` (в `api/`).
- Секреты (токен бота, ключ API) только в переменных окружения Vercel, никогда в коде.
- Проверять в браузере на ширине 375px в светлой и тёмной теме, проходить путь целиком.

```

ОБЯЗАТЕЛЬНО: перед первой анимацией вызови скилл моушн-дизайна (motion design skill) через инструмент Skill и делай все анимации по его правилам. Если скилла нет в списке, не продолжай без него: остановись и попроси пользователя установить скилл или назвать его точное имя. В итоге напиши, какие правила скилла применил.

Из данных: 253 вернувшихся ничего не запустили, профтест закрыт на бесплатном тарифе. Поэтому на S0–S5 ничего не закрыто тарифом и нет витрины до первого действия (DEV_PLAN, раздел 2).
S0. Последний вопрос анкеты: 3 группы .chip: класс (8–9 / 10 / 11–12), цель (ЕНТ / SAT / IELTS / Пока не знаю), направление (IT / Медицина / Бизнес). Кнопка «Готово» активна, когда выбраны все три. State.set({answers, profileId}). Первый тап включает звук (FX.sound('pop')).
S1. Сканер Venti, 2,5 с: 25–30 кружков с названиями вузов слетаются с краёв в центр, луч сканера идёт сверху вниз, счётчики «1 000+ вузов», «300+ грантов» бегут, строки появляются по очереди. Потом сам go('s2').
S2. Сундук: сундук трясётся, подпись «Открой свой результат». Тап → FX.flash(), FX.vibrate, FX.sound('ding'), лучи (conic-gradient синий/лайм) крутятся, карточка профессии вылетает с пружиной и переворачивается: название, % совпадения, «редкость». Ниже по очереди: ещё 2 профессии полосами, 3 вуза с match, 4-й вуз под замком «откроется завтра», кольцо «Шанс на грант» (stroke-dashoffset + FX.countUp за 1,2 с, лаймовое свечение) и 2 рычага. Подпись «пример». Кнопка «Дальше» → go('s3').
Фон #bg: 3D-звёзды как на лендинге (03_landing/site/three-hero.js — возьми подход, не копируй DOM-привязки): грузить после загрузки страницы, не грузить при reduced motion и медленной сети, рисовать только при видимой вкладке. Без WebGL — без фона, экран не ломается.
S3. Заголовок «Твой первый шаг», огромная .btn.btn-lime.btn-glow «Первый шаг за 60 секунд». Под ней только полоса «План поступления 12%» с 7 шагами (первые 2 отмечены). Внизу свёрнутый пункт «Все возможности».
S4. Мини-вызов: 3 вопроса из QUESTIONS[answers.goal], таймер-полоса на 60 с, последние 10 с краснеет и пульсирует. Верный ответ → --good, FX.sound('ding'), HUD.flyXP(кнопка, 10); неверный → --bad, FX.shake, FX.sound('error'). Объяснение в одну строку. 2 верных подряд → «×2 КОМБО». Для 'unknown' — мини-профтест без правильных ответов. State.set({challenge}).
S5. «2 из 3, твой уровень: …». Серию показывай через window.StreakFX.play(0, 1), если участник 2 её уже сделал. Затемнение, бейдж «Первые 5 минут» вылетает с 3D-переворотом, FX.confetti(), FX.sound('levelup'), XP до уровня 2. Серия: огонь с пружиной, 0 → 1 переворотом цифры, загорается сегодняшний день недели. План 12% → 25%. Замок на 4-м вузе подрагивает. State.set({streak:1, lastActive:сегодня, plan:25, badge5min:true}). Кнопка «Не потерять серию» → go('s6').
Карточка для сторис на S5: кнопка «Поделиться в сторис» собирает картинку 1080×1920 (профессия, % совпадения, уровень, серия, логотип ventorme.ai, реферальная ссылка) через canvas, отправляет через navigator.share с файлом, запасной вариант — скачать PNG.
data/profiles.js: профили med и biz по образцу it. data/questions.js: по 3 вопроса для ent, sat, ielts и 3 профтест-вопроса для unknown.
Готово, когда: путь S0 → S6 проходится на 375px в светлой и тёмной теме без ошибок в консоли, эффекты пропускаются тапом, prefers-reduced-motion учтён, повторный вход в S2 и S4 начинает их заново. Коммить в свою ветку, не в main.
```

## Как сливать

Участник 1 работает в ветке `proto-screens`, участник 2 в ветке `proto-bot`. Файлы не пересекаются, поэтому ветки сливаются в `main` без конфликтов в любом порядке. После слияния: пройти путь S0 → S7 → сброс с телефона и проверить бота с чужого телефона.
