# Прототип «Первые 5 минут»: разделение на 3 части

Прототип показывает, что видит ученик после анкеты Ventorme. Полный сценарий и эффекты описаны в [../06_final/final_plan.md](../06_final/final_plan.md), разделы 3 и 4.

Каркас уже работает: открыть `index.html`, путь S0 → S7 проходится по заглушкам. Каждый Claude заменяет заглушки **только своих экранов** и правит **только свои файлы**, поэтому три части не конфликтуют при слиянии.

## Кто что делает

| Часть | Экраны | Свои файлы (правит только он) |
|---|---|---|
| **1. Польза** | S0 последний вопрос анкеты, S1 сканер Venti, S2 сундук с результатом, фон `#bg` | `js/part1.js`, `css/part1.css`, `data/profiles.js` |
| **2. Действие и награда** | S3 одна кнопка, S4 мини-вызов 60 с, S5 level up и замок | `js/part2.js`, `css/part2.css`, `data/questions.js` |
| **3. Возврат и демо** | S6 напоминания, S7 «Завтра», демо-меню, живой Telegram-бот, деплой | `js/part3.js`, `css/part3.css`, `api/notify.js`, `vercel.json`, `DEPLOY.md` |

**Общие файлы, никто не меняет:** `index.html`, `css/base.css`, `js/state.js`, `js/router.js`, `js/fx-core.js`, `js/hud.js`, `js/main.js`. Если без изменения общего файла никак, напишите об этом в итоге работы, а не правьте сами.

## Договорённости (API каркаса)

```js
// Экран
Screens.register('s3', {
  enter: function (el, state) { el.innerHTML = '...'; },  // вызывается при каждом входе
  leave: function (el) {}                                 // по желанию: остановить таймеры
});
go('s4');                       // перейти; или кнопка <button data-go="s4">

// Состояние (localStorage, ключ vt5min-v1)
State.get();                    // { screen, answers:{grade,goal,field}, profileId, xp, level, streak,
                                //   lastActive, plan, challenge:{correct,total,done}, lockedUni,
                                //   badge5min, notify:{tg,wa,email,contact,time}, tomorrow }
State.set({ plan: 25 });        // частичное обновление, шапка обновится сама
State.addXP(30);                // → { levelUp, level }; 100 XP = уровень
State.reset();                  // сброс демо, возврат на S0
document.addEventListener('state', e => e.detail.prev / e.detail.next);

// Эффекты
FX.countUp(el, 34, { ms: 1200, suffix: '%' });
FX.confetti(); FX.flash(); FX.shake(el); FX.vibrate([30, 50, 80]);
FX.sound('ding' | 'pop' | 'error' | 'levelup');   // без файлов, после первого тапа
FX.wait(500); FX.reduced;       // reduced = пользователь просил меньше движения

// Шапка
HUD.flyXP(buttonEl, 30);        // «+30 XP» летит в шапку и начисляет XP → Promise<{levelUp}>
HUD.bump('streak' | 'level' | 'xp');
document.addEventListener('demo:menu', ...);  // тройной тап по логотипу (ловит часть 3)
```

**Что передаётся между частями через `State`:**
- Часть 1 в S0 записывает `answers.grade`, `answers.goal` (`ent`, `sat`, `ielts`, `unknown`), `answers.field` (`it`, `med`, `biz`) и `profileId`. Из S2 ведёт на `s3`.
- Часть 2 читает `answers.goal` для вопросов и `PROFILES[profileId]` для замка на 4-м вузе. В S5 ставит `streak: 1`, `lastActive`, `plan: 25`, `badge5min: true`, `challenge`. Из S5 ведёт на `s6`.
- Часть 3 в S7 ставит `streak: 2`, `lockedUni: false`, `tomorrow: true`.

**Правила для всех частей:**
- Мобильный экран до 430px, касаемые элементы от 48px, шрифт от 15px.
- Анимировать только `transform` и `opacity`. Каждый эффект не дольше 1,5 с и пропускается тапом.
- Учитывать `FX.reduced`: без движения, только появление.
- Все цифры подписаны «пример» (класс `.tag-example`).
- Классы CSS только с префиксом своих экранов (`.s2-chest`, `.s4-timer`, `.s6-toggle`), чтобы стили не пересекались.
- Внешние библиотеки только через CDN с точной версией.
- Проверять в браузере на ширине 375px, проходить путь целиком.

## Промпт для Claude №1 (Польза: S0, S1, S2)

```
Работаем в папке 07_prototype репозитория. Прочитай 07_prototype/README.md и разделы 3 и 4 файла 06_final/final_plan.md.
Ты делаешь часть 1: экраны S0, S1, S2 и фон #bg. Правь ТОЛЬКО js/part1.js, css/part1.css, data/profiles.js. Общие файлы не трогай.

S0. Последний вопрос анкеты: 3 быстрых выбора чипами: класс (8–9 / 10 / 11–12), цель (ЕНТ / SAT / IELTS / Пока не знаю), направление (IT / Медицина / Бизнес). Кнопка «Готово» активна, когда выбраны все три. Запиши State.set({answers, profileId}). Первый тап включает звук (FX.sound('pop')).
S1. Сканер Venti, 2,5 с: 25–30 логотипов-кружков с названиями вузов вылетают с краёв и всасываются в центр, луч сканера идёт сверху вниз, счётчики «1 000+ вузов», «300+ грантов» бегут, строки появляются по очереди: «Сравниваю с вузами», «Ищу гранты под тебя», «Считаю шансы». Потом сам go('s2').
S2. Сундук: сундук трясётся, подпись «Открой свой результат». Тап → FX.flash(), FX.vibrate, FX.sound('ding'), лучи (conic-gradient) крутятся, карточка профессии вылетает с пружиной и переворачивается: название, % совпадения, «редкость». Ниже по очереди: ещё 2 профессии полосами (растут от 0 с задержкой 120 мс), 3 вуза с match, 4-й вуз под замком «откроется завтра», кольцо «Шанс на грант» (stroke-dashoffset + FX.countUp за 1,2 с, лаймовое свечение) и 2 рычага под ним. Подпись «пример». Внизу кнопка «Дальше» → go('s3').
Фон #bg: canvas со звёздами и медленным параллаксом, лёгкий на телефоне (≤ 150 звёзд, requestAnimationFrame, пауза при скрытой вкладке).
data/profiles.js: допиши профили med и biz в том же формате, что it.
Готово, когда: путь S0 → S2 → S3 проходится на ширине 375px без ошибок в консоли, эффекты пропускаются тапом, при prefers-reduced-motion всё появляется без движения.
```

## Промпт для Claude №2 (Действие и награда: S3, S4, S5)

```
Работаем в папке 07_prototype репозитория. Прочитай 07_prototype/README.md и разделы 3 и 4 файла 06_final/final_plan.md.
Ты делаешь часть 2: экраны S3, S4, S5. Правь ТОЛЬКО js/part2.js, css/part2.css, data/questions.js. Общие файлы не трогай.
Для проверки без части 1 перед стартом выставь в консоли State.set({answers:{grade:'11',goal:'ent',field:'it'}, profileId:'it'}); go('s3').

S3. Одна кнопка: заголовок «Твой первый шаг», огромная кнопка .btn-lime «Первый шаг за 60 секунд», которая дышит (scale 1 → 1,04 раз в 2 с) и по которой бежит блик. Под ней только полоса «План поступления 12%» с 7 шагами (профессия, вузы, план, экзамены, эссе, стипендии, заявки; первые 2 отмечены). Внизу свёрнутый пункт «Все возможности» (6 функций Ventorme открываются по тапу).
S4. Мини-вызов: 3 вопроса из QUESTIONS[answers.goal], таймер-полоса на 60 с, последние 10 с полоса краснеет и пульсирует. Ответ: верный → зелёный, FX.sound('ding'), HUD.flyXP(кнопка, 10); неверный → красный, FX.shake, FX.sound('error'). Объяснение в одну строку. 2 верных подряд → влетает «×2 КОМБО». Для goal 'unknown' — мини-профтест без правильных ответов (каждый ответ +10 XP). Сохрани State.set({challenge}).
S5. Награда: «2 из 3, твой уровень: …» (текст по числу верных). Экран затемняется, бейдж «Первые 5 минут» вылетает в центр с 3D-переворотом, FX.confetti(), FX.sound('levelup'), начисли XP так, чтобы был уровень 2. Серия: огонь появляется с пружиной, цифра 0 → 1 переворачивается, в неделе Пн–Вс загорается сегодняшний день. Полоса плана растёт 12% → 25%. Замок на 4-м вузе из PROFILES[profileId] подрагивает: «Откроется завтра после задания». State.set({streak:1, lastActive:сегодня, plan:25, badge5min:true}). Кнопка «Не потерять серию» → go('s6').
data/questions.js: по 3 вопроса для ent, sat, ielts и 3 профтест-вопроса для unknown.
Готово, когда: путь S3 → S6 проходится на ширине 375px без ошибок в консоли, повторный вход в S4 начинает вызов заново, эффекты пропускаются тапом, при prefers-reduced-motion всё без движения.
```

## Промпт для Claude №3 (Возврат и демо: S6, S7, бот, деплой)

```
Работаем в папке 07_prototype репозитория. Прочитай 07_prototype/README.md и разделы 3, 4 и 10 файла 06_final/final_plan.md.
Ты делаешь часть 3: экраны S6, S7, демо-меню, живой Telegram-бот и деплой. Правь ТОЛЬКО js/part3.js, css/part3.css, api/notify.js, vercel.json, DEPLOY.md. Общие файлы не трогай.
Для проверки без частей 1–2: State.set({answers:{goal:'ent',field:'it'}, profileId:'it', streak:1, xp:110, level:2, plan:25}); go('s6').

S6. «Куда прислать завтрашнее задание?»: 3 переключателя (Telegram — кнопка «Подключить бота», WhatsApp — поле телефона с маской +7, почта — поле email), выбор времени (19:00 по умолчанию), живой предпросмотр сообщения в виде пузыря: «Серия 1 день 🔥 Завтра: 3 вопроса ЕНТ за 60 секунд, +30 XP. Сохрани State.set({notify}).
S7. «Завтра»: перемотка времени: циферблат, стрелки делают полный круг, подпись «Завтра, 19:00», фон экрана темнеет как вечером. Сверху падает уведомление в стиле iOS (translateY с пружиной, FX.vibrate, FX.sound('pop')). Тап по уведомлению: серия 1 → 2 (тот же переворот цифры, загораются 2 дня), замок 4-го вуза разлетается на 8 осколков, вуз открывается. State.set({streak:2, lockedUni:false, tomorrow:true}). Финальный текст «Вот так ученик возвращается» и кнопка «Начать заново» → State.reset().
Демо-меню: слушай document 'demo:menu' (тройной тап по логотипу). Шторка в #overlay-root: «Сбросить демо» (State.reset()), «Перейти в Завтра» (go('s7')), «Пропустить анкету» (заполнить answers для it/ent и go('s2')), «Закрыть».
api/notify.js: Vercel serverless (Node), POST { text } → Telegram Bot API sendMessage, токен и chat_id только из process.env.TG_BOT_TOKEN и process.env.TG_CHAT_ID, никаких секретов в коде страницы. Ограничь длину текста и разреши только POST.
vercel.json не обязателен: если нужен, только для заголовков кеша. В 07_prototype/DEPLOY.md опиши, как подключить проект к Vercel с Root Directory = 07_prototype и задать переменные.
Готово, когда: путь S6 → S7 → сброс → S0 работает на ширине 375px без ошибок в консоли, демо-меню открывается тройным тапом, без переменных окружения бот не ломает экран.
```

## Как сливать

Каждая часть работает в своей ветке (`proto-part1`, `proto-part2`, `proto-part3`). Файлы не пересекаются, поэтому ветки сливаются в `main` без конфликтов, в любом порядке. После слияния всех трёх: пройти путь S0 → S7 → сброс с телефона.
