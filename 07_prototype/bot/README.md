# Бот Ventorme AI: как запустить

Три способа, от самого простого к самому надёжному. Код один и тот же.

| Способ | Что нужно | Когда бот отвечает |
|---|---|---|
| **`bot.html`** — страница в браузере | Только токен из @BotFather | Пока открыта вкладка |
| **`npm start`** — на своём компьютере | Node.js, токен в `.env` | Пока открыто окно терминала |
| **Vercel** | Аккаунт Vercel, переменная `TG_BOT_TOKEN` | Всегда |

## Самое простое: `bot.html` (для демо)

1. Откройте файл `07_prototype/bot.html` в Chrome. Можно скачать его с GitHub или открыть `https://<сайт>/bot.html`, если сайт уже на Vercel.
2. Вставьте токен бота и нажмите «Запустить бота».
3. Откройте @VentormeAI_bot в Telegram и нажмите «Старт».

Сообщения, отправленные боту за 10 минут до запуска, бот тоже обработает. Если браузер не пускает страницу к Telegram напрямую, она сама переключится на прокси `api/tg.js` на Vercel (в журнале будет «через сервер Vercel»).

Ноутбук не должен уснуть, вкладку не закрывать. Данные бота живут, пока открыта вкладка. Без ключа Claude Venti отвечает готовыми ответами (`faq.js`). Задания, профиль, `/demo_tomorrow` и все 26 команд работают.

Одновременно бот может слушать только одно место: `bot.html`, `npm start` или Vercel. Страница при запуске снимает вебхук Vercel; чтобы вернуть бота на Vercel, откройте `/api/setup`.

## Как устроено

| Файл | Что делает |
|---|---|
| `handlers.js` | Команды, кнопки, задание дня, напоминания |
| `texts.js`, `commands.js` | Все тексты и список команд |
| `tasks.js` | Вопросы задания дня |
| `faq.js` | Готовые ответы Venti без ИИ |
| `venti.js` | Ответы Venti через Claude API (если есть `ANTHROPIC_API_KEY`) |
| `store.js`, `memory.js` | Upstash Redis или память |
| `tg.js` | Запросы к Telegram Bot API |
| `local.js` | `npm start`: сайт на localhost и бот через long polling |
| `demo.js`, `demo.html`, `build-demo.mjs` | Страница `bot.html`: `npm run build:demo` собирает её в один файл |
| `../api/tg.js` | Запасной путь для `bot.html`: если браузер не пускает страницу к Telegram напрямую, запросы идут через этот прокси на Vercel (только бот @VentormeAI_bot) |
| `secret.js`, `env.js` | Секреты и переменные окружения для `api/*` |

После правок в `bot/*.js` пересоберите страницу: `npm install && npm run build:demo`.
