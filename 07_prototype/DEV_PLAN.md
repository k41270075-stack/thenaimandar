Сценарий и эффекты описаны в [../06_final/final_plan.md](../06_final/final_plan.md) (разделы 3–5). API каркаса, файлы и промпты для Claude — в [README.md](README.md). Этот файл объясняет, **в каком порядке** каждый участник работает и **когда его работа считается готовой**.

## 0. Обязательно для обоих

### Скилл моушн-дизайна
**Перед первой строкой анимации каждый Claude вызывает скилл моушн-дизайна (motion design skill) через инструмент Skill** и строит все анимации по его правилам: тайминги, кривые, хореография, отклик на касание, reduced motion.
- Вызывается на этапе 2, до любого `@keyframes`, `transition` или `requestAnimationFrame`.
- Если скилла нет в списке, **не продолжать без него**: остановиться и попросить пользователя установить скилл или назвать точное имя.
- В итоге работы написать, какие правила скилла применены и где.
- Скилл главнее плана в вопросе **как анимировать**, план главнее в вопросе **что анимировать**.

### Один стиль с лендингом
Прототип выглядит как продолжение нашего лендинга `03_landing/site`: те же токены, кнопки-пилюли со стрелкой в круге и бликом, вложенные панели, чипы, волосяные линии, северное сияние, 3D-звёзды, системный шрифт, светлая и тёмная тема. Всё это уже лежит в `css/base.css`. **Новых цветов, шрифтов и стилей кнопок не заводим.** Сообщения бота пишем тем же голосом, что и тексты лендинга: коротко, на «ты», без канцелярита.

### Общие правила движения
| Правило | Значение |
|---|---|
| Что анимируем | Только `transform` и `opacity` (плюс `stroke-dashoffset` для колец) |
| Длительность | Отклик на тап 80–150 мс, переход 250–320 мс, «вау»-момент не дольше 1,5 с |
| Кривые | Обычные переходы `var(--ease)` (как на лендинге), «вау»-появления `var(--ease-spring)`, линейная только у таймера |
| Пропуск | Эффект длиннее 600 мс пропускается тапом и сразу показывает итог |
| Хореография | Элементы появляются по очереди с шагом 60–120 мс, главный первым, кнопка «дальше» последней |
| Reduced motion | Если `FX.reduced`: без движения, тряски и конфетти, только появление за 150 мс |
| Тактильность и звук | `FX.vibrate` и `FX.sound` только на ключевых моментах, звук после первого тапа |
| Производительность | 60 кадров/с на среднем Android: до 150 частиц, без `box-shadow` и `filter` в анимации |

## 1. Этапы и время

| Этап | Время | Участник 1 | Участник 2 | Контрольная точка |
|---|---|---|---|---|
| 1. Статика | 0:00–0:50 | S0–S5 без анимаций, данные, переходы | Бот: `/start`, хранилище, задание дня с кнопками; S6 и S7 без анимаций | Путь S0 → S7 проходится с телефона; бот отвечает на `/start` |
| 2. Главное | 0:50–1:50 | **Вызвать скилл моушн-дизайна**, эффекты ★ | ИИ-ответы Venti, напоминания по cron, деплой на Vercel; **скилл моушн-дизайна**, эффекты ★ в S6–S7 | Сундук, вызов, level up работают; бот живой по ссылке |
| 3. Полировка | 1:50–2:30 | Эффекты ●, reduced motion, тёмная тема, iPhone и Android | Демо-меню, эффекты ●, защита бота от ошибок, `DEPLOY.md` | Чек-листы закрыты |
| 4. Сдача | 2:30–2:40 | Коммит в `proto-screens` | Коммит в `proto-bot` | Ветки готовы к слиянию |

Если время поджимает: делаем только ★, остальное оставляем статичным. Статичный экран, который работает, лучше анимированного, который ломается. Для бота порядок важности: `/start` → задание дня → ИИ-ответ → напоминание по cron.

## 2. Участник 1 — Экраны S0–S5

**Файлы:** `js/part1.js`, `css/part1.css`, `data/profiles.js` (S0–S2, фон) и `js/part2.js`, `css/part2.css`, `data/questions.js` (S3–S5). Можно вести двумя Claude параллельно.

**Этап 1. Статика**
1. S0: три группы `.chip`, «Готово» неактивна, пока не выбраны все три. `State.set({answers, profileId})`.
2. S1: строки и счётчики, через 2,5 с `go('s2')`.
3. S2: сундук → карточка профессии, 2 полосы профессий, 3 вуза, 4-й под замком, кольцо шанса на грант, 2 рычага, подпись «пример», кнопка → `s3`.
4. S3: `.btn.btn-lime.btn-glow` «Первый шаг за 60 секунд», полоса плана 12% с 7 шагами, свёрнутые «Все возможности».
5. S4: 3 вопроса из `QUESTIONS[answers.goal]`, таймер 60 с, проверка, объяснение, счёт; для `unknown` мини-профтест.
6. S5: итог, бейдж, серия, неделя Пн–Вс, план 12% → 25%, замок. `State.set({streak:1, lastActive, plan:25, badge5min:true, challenge})`, кнопка → `s6`.
7. Данные: профили `med`, `biz`; по 3 вопроса для `ent`, `sat`, `ielts`, `unknown`.

**Этап 2. Моушн (сначала вызвать скилл)**
| Приоритет | Эффект | Ориентир |
|---|---|---|
| ★ | Сундук: тряска в ожидании, тап → вспышка, вибрация, звук, лучи синий/лайм крутятся, карточка вылетает с пружиной и переворачивается | до 1,2 с |
| ★ | Level up на S5: затемнение, бейдж с 3D-переворотом, конфетти в цветах бренда, «Уровень 2» | до 1,5 с |
| ★ | Ответ в S4: верный — зелёный и `HUD.flyXP`; неверный — красный и `FX.shake` | 0,3–0,6 с |
| ★ | Кольцо шанса на грант: `stroke-dashoffset` и счёт одновременно, лаймовое свечение | 1,2 с |
| ● | Сканер S1: кружки вузов слетаются в центр, луч, бегущие счётчики | 2,5 с |
| ● | Серия: огонь с пружиной, переворот цифры 0 → 1, загорается день | 1,2 с |
| ● | «×2 КОМБО», краснеющий таймер, полосы профессий растут по очереди | 0,5 с |
| ● | Карточка для сторис на S5: кнопка «Поделиться в сторис» собирает картинку 1080×1920 (профессия, %, уровень, серия, логотип, реферальная ссылка) и открывает `navigator.share` с файлом; запасной вариант — скачать PNG. Карточка появляется с пружиной | 0,5 с |

## 3. Участник 2 — Бот Ventorme AI, S6, S7, деплой

**Файлы:** `js/part3.js`, `css/part3.css`, `api/*`, `bot/*`, `package.json`, `vercel.json`, `DEPLOY.md`.

### 3.1. Как устроен бот

```
Ученик на S6 → кнопка «Подключить Venti» → t.me/<бот>?start=it_ent_11
     ↓
Telegram → POST /api/telegram (вебхук)
     ├─ /start it_ent_11  → сохранить профиль, приветствие с результатом, серия 1, кнопки
     ├─ кнопка «Задание»  → 3 вопроса с inline-кнопками → XP, серия
     ├─ любой текст        → ИИ-ответ Venti (Claude API)
     └─ /stop              → отписка в один тап
Vercel Cron 14:00 UTC (19:00 Астана) → GET /api/remind → задание дня всем подписанным
```

| Файл | Что делает |
|---|---|
| `api/telegram.js` | Вебхук. Проверяет заголовок `X-Telegram-Bot-Api-Secret-Token` = `TG_WEBHOOK_SECRET`, иначе 401. Разбирает `message` и `callback_query`, всегда отвечает 200 быстро |
| `api/remind.js` | Вызывается Vercel Cron. Проверяет `Authorization: Bearer ${CRON_SECRET}`. Шлёт задание дня тем, кто подписан и ещё не получил сегодня |
| `bot/store.js` | Upstash Redis: `user:<chat_id>` → `{profile, goal, grade, streak, xp, lastActive, subscribed, lastSent}`; `hist:<chat_id>` → последние 6 реплик для ИИ |
| `bot/venti.js` | Вызов Claude API: системный промпт Venti, история, ограничения |
| `bot/tasks.js` | Вопросы задания дня по `goal` (можно взять формат из `data/questions.js`, но файл свой) |
| `bot/texts.js` | Все тексты бота в одном месте, на русском, тем же голосом, что лендинг |
| `vercel.json` | `crons: [{ path: "/api/remind", schedule: "0 14 * * *" }]` |
| `package.json` | `@anthropic-ai/sdk`, `@upstash/redis` |

**Переменные окружения (Vercel):** `TG_BOT_TOKEN`, `TG_WEBHOOK_SECRET`, `ANTHROPIC_API_KEY`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `CRON_SECRET`, `TG_ADMIN_IDS` (кому доступна `/demo_tomorrow`). Без любой из них функция отвечает 503 и пишет понятную ошибку в лог; страница прототипа от этого не ломается.

### 3.2. Команды и сценарии

| Команда / действие | Ответ бота |
|---|---|
| `/start it_ent_11` | «Привет! Я Venti из Ventorme. Твой результат: AI-аналитик, 96% совпадения. Серия: 1 день 🔥. Завтра в 19:00 пришлю задание на 60 секунд.» Кнопки: «Задание сейчас», «Спросить Venti», «Мой план» |
| `/start` без payload | Короткое приветствие и 3 кнопки выбора цели (ЕНТ / SAT / IELTS) |
| «Задание сейчас» / `/task` | 3 вопроса по очереди, inline-кнопки ответа, после ответа правильный вариант и одна строка объяснения, итог «2 из 3, +30 XP, серия 2 дня» |
| Любой текст | Ответ Venti от ИИ (раздел 3.3), под ним кнопки «Задание», «Ещё вопрос» |
| `/stop` | «Готово, больше не пишу. Вернуться: /start». Ставит `subscribed: false` |
| `/help` | Список команд |
| `/demo_tomorrow` | Только для `TG_ADMIN_IDS`: сразу присылает «завтрашнее» напоминание, для показа на защите |
| Cron 19:00 | «Серия 1 день 🔥 Сегодня: 3 вопроса ЕНТ за 60 секунд, +30 XP» + кнопка «Начать». Не больше 1 сообщения в день, только подписанным |

### 3.3. ИИ-помощник Venti (Claude API)

Перед кодом **вызвать скилл claude-api** и писать по нему, через официальный SDK `@anthropic-ai/sdk`.

| Параметр | Значение |
|---|---|
| Модель | `claude-opus-5-5` (по умолчанию из скилла). Если команде важна цена, решите сами про `claude-haiku-5-5` |
| Усилие | `output_config: { effort: "low" }`: короткие ответы в чате, быстро |
| Длина | `max_tokens` около 1 000, в промпте «до 600 символов, 2–4 абзаца» |
| Отказы | Проверять `stop_reason`: при `"refusal"` мягкий заготовленный ответ, без ошибки |
| История | Последние 6 реплик из Redis, без лишних личных данных |
| Лимит | До 20 ИИ-ответов на ученика в день, дальше «Давай продолжим завтра» |
| Ошибки API | Повтор SDK по умолчанию, при сбое заготовленный ответ и кнопка «Задание» |

**Системный промпт Venti (суть):** ты Venti, помощник Ventorme для школьников 13–18 лет из Казахстана, которые готовятся к поступлению. Помогаешь с выбором профессии и вуза, ЕНТ, SAT, IELTS, грантами, эссе и планом подготовки. Пишешь коротко, на «ты», дружелюбно, на языке ученика (русский или казахский). Знаешь профиль ученика: класс, цель, направление. Не выдумываешь цифры и дедлайны: если не уверен, говоришь, где проверить на Ventorme. Не собираешь личные данные. Не решаешь домашку целиком, а объясняешь ход. Вопросы не про учёбу и поступление мягко возвращаешь к теме. Если ученик пишет о беде, опасности или плохом самочувствии, бережно советуешь поговорить со взрослым, которому доверяет, и даёшь номер детской линии доверия Казахстана (номер проверить перед защитой).

## 4. Слияние и общая проверка

1. Ветки `proto-screens` и `proto-bot` сливаются в `main` в любом порядке: файлы не пересекаются.
2. Один человек проходит путь S0 → S7 → сброс трижды подряд на iPhone и Android, в светлой и тёмной теме.
3. Стыки: S2 → S3 (профиль доходит до замка в S5), S5 → S6 (серия и XP видны в шапке, payload в ссылке на бота правильный), S7 → S0 (сброс очищает всё).
4. На телефоне спикера бот подключён заранее, `/demo_tomorrow` проверена.
5. Деплой по `DEPLOY.md`, ссылка с чужого телефона, QR на последний слайд.
6. В 15:00 заморозка: дальше только исправление ошибок.
